# v0.18 development

v0.17 remains the packaged stable prototype. v0.18 development is not yet a
complete original-engine or full-city port. No v0.18 release has been published. The current native gameplay world and
controller are still the v0.17 prototype while the new backend is tested.

Current integration:

- Original GameCube body/title fonts, logo and frontend artwork in a bounded UI sidecar.
  Two-screen composition and functional menu entries are adapted for this port;
  recovered source artwork is not proof of original frontend behavior.
- Neutral rendering by default. Display settings expose optional `Piss filter`.
  The current cheap warm grade is artistic, not the original bloom pipeline.
  Original post-effect curves/consumers are being recovered separately.
- Canonical hero PSRTEST diffuse preview from the original career preset, native
  palette adapters and verified mask blending. Source GLOSS is separate from
  opacity. Indexed edge quantization and full reflective lighting remain open.
- All 23,112 original car corner normals supplied, with position/UV/order
  correspondence verified; the existing inspection shader remains provisional.
- World decoder opt-in for original draw-count statistic discrepancies, retaining
  source bytes and all geometry constraints. All 168 affected source models
  match the prior original-code-verified diagnostic; default decoder stays strict.
  LOD consumes the original statistic, which is preserved unchanged.
- Complete source stream converted into bounded model/texture/instance assets;
  native readers/expansion verified. Actual streamed Citro3D renderer integration
  and loading transitions are underway, not claimed complete.

Runtime components in specialist integration/testing:

- Original complete per-wheel contact solver and drivetrain numerical/policy
  components; vehicle-state producers,
  drivetrain, suspension and whole-car response still need closure.
- Compact original region/section metadata, exact contained-region selection,
  request planning and explicit readiness/resource accounting. Full asset
  conversion, asynchronous IO, fixups and render registration remain required.
- Packed original collision banks with exact source-section membership and
  bounded runtime activation. Original body response remains a separate gate.
- Canonical `M3GTRCAREERSTART` preset from the newly supplied native GlobalB;
  source livery/paint parts identified, compositor export being verified.

Evidence and screenshots live under `/workspace/port-research/rockport/v0.18-dev`.
Original frontend/preset input hashes and directory-range checks are recorded in
`/workspace/port-research/v018-inputs.json`; decoded bundle hashes are recorded in
`/workspace/port-research/v018-decoded/decoded-inputs.json`.

Acceptance requires coherent runtime integration and comparison with original
behavior. Scalar parity, source-data possession and emulator FPS do not establish
1:1 whole-game fidelity or stock-console performance.
