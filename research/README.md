# Research checkpoint

These are snapshots of authored notes, source-data provenance and comparison
reports. They record component-level recovery and do not establish a completed
1:1 game or hardware performance. Current development sources live in the
normal include/source/tools/tests directories.

Original game inputs, converted meshes/textures, executable builds, large
generated catalogues, external reference packages and emulator/SDK caches are
not copied here. Keep the private full-directory ZIP backups and original
inputs; use the committed tools to reproduce asset-dependent analysis.

INDEX.json lists every copied document, its SHA-256 and omitted large/changing
documents. Refresh with `python3 tools/snapshot_research_notes.py` from the
restored workspace at a stable checkpoint. Historical notes can contain earlier
interpretations; later verified corrections and current source APIs take
precedence.
