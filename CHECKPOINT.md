# Recovered v0.18 development checkpoint

This branch preserves recovered source, tools, tests and development notes. It is
a work-in-progress checkpoint, not a v0.18 gameplay release or a completed 1:1 port.
The public README and prior main history are preserved.

The existing prototype has a partial Rockport scene and provisional handling.
Original physics, collision, camera and full-map streaming components are being
recovered and tested; not all are integrated into gameplay. See V0.18.md and the
research notes under tools/.

Game archives, converted game assets, generated executables, SDK images and
emulator caches are not included in Git. Full recovered working-directory
backups were created and SHA-256-verified on 2026-11-03; retain those private
backups and original inputs to reproduce asset-dependent checks.
